# Portfolio with Bootstrap and Sass

A responsive personal portfolio website built with Bootstrap 5, Font Awesome, and custom Sass styles.

## Getting started

Run `npm install`, then `npm run compile:sass` to watch and compile Sass. Open `index.html` through a local static web server.
